# Online Invitations — Starter

This repository contains a minimal Next.js + TypeScript starter configured with Tailwind CSS, React Hook Form and Zod for validating forms.

Quick start

```bash
# install dependencies
npm install

# run dev server
npm run dev
```

Notes

- Tailwind resources are in `styles/globals.css`.
- Example form component is at `components/InviteForm.tsx`.
